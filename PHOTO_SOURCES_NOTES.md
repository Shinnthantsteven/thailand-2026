# Photo upgrade notes

This version uses actual online photos where possible, mainly Wikimedia Commons Special:FilePath links for public places and food.

Important:
- Public attractions and food cards use real photo URLs when available.
- Hotel photos are not copied from Google/Booking/Agoda because those images are usually copyrighted and not safe to embed directly.
- Hotel cards include Google Maps buttons so you can open the real hotel photo gallery legally from Google Maps.
- Some niche places may still fallback to the designed visual card if the web image fails or no safe reusable photo was found.

Main source types:
- Wikimedia Commons / Creative Commons
- Google Maps links for hotel/place photo galleries
