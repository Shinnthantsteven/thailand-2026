# Thailand 2026 Premium Maps Visual App

This version includes:
- Premium dashboard UI
- Generated-style visual cards instead of broken external photos
- Region-by-region explanations
- Food guide with safe food notes
- Transport command center
- Google Maps search links for each activity
- Google Maps directions links for key transfers
- Same latest final itinerary and budget rules

How to use:
1. Copy everything from this folder into your GitHub repo folder.
2. Run: npm install
3. Run: npm run build
4. Run:
   git add .
   git commit -m "Upgrade Thailand app premium UI with maps"
   git push
